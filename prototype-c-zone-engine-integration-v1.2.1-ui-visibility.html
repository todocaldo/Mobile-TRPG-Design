Expedition Details▼
Camp: Rally +2 Def (both types) · Forest / Ruins: Cover (+4 Def vs ranged attacks from outside) · Hill: High Ground (+1 range) · Watchtower: unlimited ranged targeting, 1 occupant max
Each round opens with a Deployment phase (Pre-Battle before Round 1, then "after Round N" before every round after) sharing its 5 CP with the round that follows. Mercenaries deployed in that phase are ready to act as soon as combat begins. Each unit then acts once per round, in initiative order, spending up to 3 CP that turn.
An Ambusher starts hidden in one non-Camp, non-Watchtower zone. It stays invisible and untargetable until a mercenary moves into its zone, at which point it strikes that mercenary immediately for free, then joins the fight as a normal visible enemy from then on.
Damage uses an Attack-vs-Defense effectiveness curve: Defense = Attack → 50% effectiveness, Defense = 0 → 100%, Defense = 2×Attack → 0%. Negative Defense (from debuffs or armor-piercing skills) can push effectiveness above 100%.
